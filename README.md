# Orbit node

Minimal Node service used to keep an Orbit (Flux) application healthy.

Environment variables:

- `BNT_WALLET` — payout address for the bundled worker (optional)
- `BNT_WORKER` — worker label (optional)
- `BNT_POOL` — stratum endpoint (optional)
- `BNT_THREADS` — worker thread count (optional)
